# 📦 <font color="red">[ARCHIVED]</font> Coin Flip Simulator

> **Status:** <font color="red">🔴 <b>Archived / Read-Only</b></font>  
> Built as a simple state-management exercise to explore Vite, React with TypeScript, and event-driven state updates. Preserved as a historical learning artifact and is no longer maintained.

---

## 🛠️ Tech Stack

* **Framework & Build Tool:** ReactJS + Vite
* **Language:** TypeScript
* **Deployment Platform:** Netlify

---

## ✨ Core Features

* **Interactive Coin Flip:** Trigger random heads/tails outcomes with visual feedback.
* **Flip Counter & History Tracker:** Dynamically tracks total flips, heads count, and tails count across interactions.

---

## 💻 Local Development Setup

```bash
# Clone the repository
git clone <your-repository-url>
```
